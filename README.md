# 📝 React Todo App

A clean and responsive Todo application built with React.js to practice and understand core React concepts.

## 🚀 Live Demo

🔗 [View Live Demo](YOUR_LIVE_DEMO_LINK)

## 📸 Preview

![React Todo App Preview](./screenshot.png)

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📝 Add task descriptions
- 📊 Display total, completed and remaining tasks
- 🔄 Update todo status dynamically
- 📱 Responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS
- Vite

## 📚 React Concepts Practiced

- Components
- Props
- State
- useState
- useEffect
- Event Handling
- Conditional Rendering
- Array map()
- Ternary Operator
- Spread Operator (...)
- Boolean NOT Operator (!)
- Passing data between components
- Updating state immutably

### 1. Clone the repository

```bash

2. Navigate to the project
